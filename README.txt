SMARTCLG - MGMCET KAMOTHE EVENT WEBSITE
========================================

HOW TO OPEN
----------
1. Extract this ZIP file completely.
2. Double-click START_WEBSITE.bat to start the website.
3. Your browser will open http://localhost:8765

If START_WEBSITE.bat cannot run, double-click START_HERE.html instead.

IMPORTANT
---------
- Do not open the ZIP file directly in a browser.
- Extract the ZIP first.
- Keep the assets folder in the same place as index.html.

The website includes public pages, Admin portal, Student portal, events,
registration records, venue management, official MGMCET photos, calendar,
college profile, contact information, CSV export, and light/dark themes.
